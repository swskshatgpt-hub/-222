ลำดับเลขคณิต (Arithmetic Sequence)

ผลต่างร่วม ($d$) คงที่ระหว่างพจน์ถัดไป

ลำดับเลขคณิตคือลำดับที่ผลต่างของพจน์ที่ $n+1$ กับพจน์ที่ $n$ มีค่าคงตัวเสมอ เรียกว่า ผลต่างร่วม ($d$)

สูตรพจน์ทั่วไป ($a_n$)

$$a_n = a_1 + (n - 1)d$$

สูตรผลบวก $n$ พจน์แรก ($S_n$)

$$S_n = \frac{n}{2}[2a_1 + (n-1)d] = \frac{n}{2}(a_1 + a_n)$$

ลำดับเรขาคณิต (Geometric Sequence)

อัตราส่วนร่วม ($r$) คงที่ระหว่างพจน์ถัดไป

ลำดับเรขาคณิตคือลำดับที่อัตราส่วนของพจน์ที่ $n+1$ ต่อพจน์ที่ $n$ มีค่าคงตัวเสมอ เรียกว่า อัตราส่วนร่วม ($r$)

สูตรพจน์ทั่วไป ($a_n$)

$$a_n = a_1 r^{n-1}$$

สูตรผลบวก $n$ พจน์แรก ($S_n$)

$$S_n = \frac{a_1(r^n - 1)}{r - 1} \quad (r \neq 1)$$

ทดสอบความเข้าใจเรื่องลำดับและอนุกรม พร้อมเฉลยวิธีทำอย่างละเอียด

คะแนนที่คุณทำได้ 0 / 3
ข้อที่ 1 ลำดับเลขคณิต

กำหนดลำดับเลขคณิตมีพจน์แรก $a_1 = 5$ และพจน์ที่ $4$ คือ $20$ จงหาผลต่างร่วม ($d$)

เฉลยวิธีทำ:

จากสูตร $a_n = a_1 + (n-1)d$ แทนค่า $a_4 = 20, a_1 = 5, n = 4$
$20 = 5 + (4-1)d \Rightarrow 15 = 3d \Rightarrow d = 5$ (ตอบข้อ B)

ข้อที่ 2 ลำดับเรขาคณิต

ลำดับเรขาคณิตชุดหนึ่งมี $a_1 = 2$ และอัตราส่วนร่วม $r = 3$ จงหาพจน์ที่ $4$ ($a_4$)

เฉลยวิธีทำ:

จากสูตร $a_n = a_1 r^{n-1}$ แทนค่า $a_1 = 2, r = 3, n = 4$
$a_4 = 2 \times 3^{4-1} = 2 \times 3^3 = 2 \times 27 = 54$ (ตอบข้อ C)

ข้อที่ 3 อนุกรมเลขคณิต

จงหาผลบวกของอนุกรมเลขคณิต $1 + 3 + 5 + \dots + 19$

เฉลยวิธีทำ:

จาก $a_1 = 1, d = 2, a_n = 19$
หา $n$ จาก $19 = 1 + (n-1)2 \Rightarrow 18 = 2(n-1) \Rightarrow n = 10$
จากสูตร $S_n = \frac{n}{2}(a_1 + a_n) = \frac{10}{2}(1 + 19) = 5 \times 20 = 100$ (ตอบข้อ C)
